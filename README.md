# Expense Tracker

Учебное веб-приложение для ведения личных финансов на Laravel. Проект помогает учитывать доходы и расходы, планировать бюджеты, создавать регулярные операции и накопления.

## Возможности

* CRUD категорий доходов и расходов
* CRUD транзакций с фильтрацией и пагинацией
* импорт и экспорт транзакций в CSV
* общий месячный бюджет и бюджеты отдельных категорий
* предупреждение о приближении к лимиту бюджета
* регулярные транзакции по расписанию
* финансовые цели с пополнениями, снятиями и расчётом прогресса
* сводная страница с доходами, расходами и балансом за выбранный период
* личные и совместные счета с переключением и отдельными наборами финансовых данных
* настройки валюты, отображения копеек, количества записей на странице и порога предупреждения бюджета

## Архитектура

Для операций изменения данных в проекте используется следующий поток:

```
HTTP-запрос
      ↓
Form Request — авторизация и валидация
      ↓
DTO — типизированные входные данные
      ↓
Policy — проверка прав пользователя
      ↓
Action — выполнение одного сценария
      ↓
Eloquent — работа с базой данных
```

Сервисы используются там, где нужна отдельная вычислительная логика. Например:

* `DashboardService` собирает данные для сводной страницы;
* `BudgetUsageService` рассчитывает использование бюджета;
* `GoalProgressService` рассчитывает прогресс финансовой цели;
* `RecurringScheduleService` определяет следующую дату регулярной операции;
* `TransactionCsvService` читает и формирует CSV.

## Установка

```
composer install
cp .env.example .env
./vendor/bin/sail up -d
./vendor/bin/sail artisan migrate --seed
./vendor/bin/sail npm install
./vendor/bin/sail npm run dev
```

## Регулярные транзакции

Команда обработки запланированных операций:

```
./vendor/bin/sail artisan transactions:process-recurring
```

Она запускается планировщиком каждую минуту. Для запуска планировщика во время локальной разработки:

```
./vendor/bin/sail artisan schedule:work
```
